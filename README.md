# AntiAlienate MCP — the open knowledge network for parental alienation

**One command connects your AI to the largest open-source knowledge base dedicated to parental alienation:**

```
claude mcp add antialienate --transport http https://mcp.antialienate.com
```

ChatGPT: add `https://mcp.antialienate.com` as a custom MCP connector.

## What your AI gains

- **299 case-law summaries** across **359 jurisdictions** — searchable, citable
- **35 anonymized case studies** and **28 evidence & documentation guides**
- **29 vetted practitioners** (therapists & lawyers who understand alienation)
- **The Alienation Playbook** — the 5 recurring tactic patterns with recognition signs and documentation counters
- All content **CC-BY-4.0**, served from [knowledge.antialienate.com](https://knowledge.antialienate.com)

## Tools

| Tool | Purpose |
|---|---|
| `search_knowledge` | Search case law, case studies, practitioners, evidence guides, jurisdictions |
| `get_entry` | Fetch any full entry as JSON |
| `get_playbook` | The 5 alienation patterns + first-72-hours guidance |
| `about_network` | Network info and next steps |

## The principle

**Expose patterns, never people.** This network shares knowledge and anonymized patterns. Your evidence belongs in your own private, dated record — and in court. Public accusation helps the alienator; organized documentation helps your child.
